===

1. Захват через DXGI Desktop Duplication API
2. GPU -> GPU copy
3. NVENC / x264 encode
4. RTMP push
```
HWND
->
DXGI Desktop Duplication
->
D3D11 texture
->
Encoder (NVENC / x264 / AMF)
->
RTMP
```

Шаг 1 — получить координаты окна
```catcher.rs
use windows::Win32::UI::WindowsAndMessaging::GetWindowRect;
use windows::Win32::Foundation::RECT;

pub fn get_window_rect(hwnd: HWND) -> Option<(i32, i32, i32, i32)> {
    unsafe {
        let mut rect = RECT::default();
        if GetWindowRect(hwnd, &mut rect).as_bool() {
            let width = rect.right - rect.left;
            let height = rect.bottom - rect.top;
            Some((rect.left, rect.top, width, height))
        } else {
            None
        }
    }
}
```
Шаг 2 — запуск ffmpeg по region
Где:
```
offset_x = rect.left
offset_y = rect.top
video_size = width x height
```
Шаг 3  Rust код
внутри on_window_selected:
```win_ui.rs
use std::process::Command;
use windows_backend::catcher::get_window_rect;

ui.app.on_window_selected(move |index| {
    let windows = cache.borrow();
    if let Some(selected) = windows.get(index as usize) {

        if let Some((x, y, w, h)) = get_window_rect(selected.hwnd) {

            println!("Recording HWND {:?} at {},{} size {}x{}", selected.hwnd, x, y, w, h);

            Command::new("ffmpeg")
                .args([
                    "-y",
                    "-f", "gdigrab",
                    "-framerate", "60",
                    "-offset_x", &x.to_string(),
                    "-offset_y", &y.to_string(),
                    "-video_size", &format!("{}x{}", w, h),
                    "-i", "desktop",
                    "-c:v", "libx264",
                    "-preset", "veryfast",
                    "output.mp4",
                ])
                .spawn()
                .expect("failed to start ffmpeg");
        }
    }
});
```
```
HWND → RECT → desktop crop → MP4
```
 Важные моменты
1. Если окно двигается — запись останется на старом месте.
2. Если окно свернуто — будет чёрный экран.
3. Если перекрыто — захватит перекрытие.

Это ограничения `gdigrab`.
