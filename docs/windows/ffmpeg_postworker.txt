Пособработка:
1. audio_engine  пишет звук системы в файл
2️. видео пишется как сейчас
3️. после StopRecord запускается ffmpeg постобработка
4️. ffmpeg делает
- исправление цвета
- mux audio+video
Архитектура
```
Start Record
     │
     ├── RecordEngine → output_video.mp4
     │
     └── AudioEngine  → output_audio.wav


Stop Record
     │
     ▼
ffmpeg postprocess

ffmpeg
   -i output_video.mp4
   -i output_audio.wav
   -vf format=rgba
   -c:v libx264
   -c:a aac
   final_output.mp4
```
Постобработка может занять несколько секунд 0 это нормально
