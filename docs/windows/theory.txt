Механизм захвата окон в Windows основан на комбинации legacy API (BitBlt, PrintWindow) и современных (Windows.Graphics.Capture, WGC), которые обеспечивают эффективный захват кадров без полного скриншота экрана.
https://blogs.windows.com/windowsdeveloper/2019/09/16/new-ways-to-do-screen-capture/
===
Теоретическая часть и API
---
Основные внутренние API:  
- User32.dll: EnumWindows для перечисления окон,
- FindWindowEx/GetWindow для поиска по заголовку/классу/процессу, 
- GetWindowRect/GetClientRect для размеров, 
- IsWindowVisible/GetForegroundWindow для фильтрации видимых окон (включая игры/видео по PID или классу вроде "SDL_app", "Chrome")
https://stackoverflow.com/questions/3188484/windows-how-to-get-a-list-of-all-visible-windows
- Dwmapi.dll: DwmGetWindowAttribute (DWMWA_EXTENDED_FRAME_BOUNDS) для точных границ окон с учётом DPI и рамок
https://www.autohotkey.com/boards/viewtopic.php?style=19&t=96161
- Gdi32.dll/User32: PrintWindow (legacy) или BitBlt для копирования DC (Device Context) окна в текстуру
https://stackoverflow.com/questions/11283015/screen-capture-specific-window
- Windows.Graphics.Capture (WinRT): GraphicsCaptureItem::CreateForWindow(HWND) для создания сессии захвата, 
- GraphicsCaptureSession и Direct3D11CaptureFramePool для буферизации кадров в D3D11 текстуру. Требует Windows 10 1803+, работает асинхронно с событиями FrameArrived. 
https://learn.microsoft.com/en-us/windows/uwp/audio-video-camera/screen-capture-video
---
Получение списка окон с EnumWindows с колбэком:
- перечисляет все топ-левел окна (GW_OWNER),
фильтруeт:
- по WS_VISIBLE,
- заголовку (GetWindowText),
- классу (GetClassName),
- exe (GetWindowThreadProcessId + GetModuleFileNameEx).
Для игр/видео:
- проверяют классы вроде "XLMAIN" (Excel),
- "SDL_app" или процессы по PID.
Фильтрация по minimized (IsIconic)
https://stackoverflow.com/questions/10246444/how-can-i-get-enumwindows-to-list-all-windows/47432615
---
Передача видео между окнами
Захват: Получаем кадры в D3D11/ID3D11Texture2D (WGC) или bitmap (BitBlt), конвертируем в RGBA/ARGB. Передача — рендер текстуры в целевое окно через DirectX (gs_texture в OBS, DrawTexture в custom рендерере): копируем в GPU-текстуру, масштабируем/компонуем в сцену. Асинхронно через FrameArrived, с dirty regions для оптимизации (только изменённые области). Для видео — энкодинг в H.264/AV1 через MediaFoundation
https://github.com/obsproject/obs-studio/blob/master/plugins/win-capture/window-capture.c
