Экран/окно Wayland
Wayland специально сделан так, чтобы:
- нельзя читать экран
- нельзя читать окно
- нельзя читать чужие буферы

единственный легальный путь:
App -> xdg-desktop-portal -> compositor -> PipeWire -> наши фреймы

Чтение кадров в Rust 
Например размер кадра:
- width = 1920
- height = 1080
- rgb24 -> 3 байта на пиксель
```text
frame_size = 1920 * 1080 * 3
```
```rust
use std::process::{Command, Stdio};
use std::io::Read;

fn main() -> std::io::Result<()> {
    let mut child = Command::new("ffmpeg")
        .args([
            "-f", "pipewire",
            "-i", "110",
            "-f", "rawvideo",
         я   "-pix_fmt", "rgb24",
            "-"
        ])
        .stdout(Stdio::piped())
        .stderr(Stdio::null())
        .spawn()?;

    let mut stdout = child.stdout.take().unwrap();

    let width = 1920;
    let height = 1080;
    let frame_size = width * height * 3;

    let mut frame = vec![0u8; frame_size];

    loop {
        stdout.read_exact(&mut frame)?;
        println!("got frame: {} bytes", frame.len());

        // тут:
        // - upload to GPU
        // - encode
        // - analyze
    }
}
```

Как получить ffmpeg с pipewire
1. Flatpak ffmpeg
```bash
flatpak install flathub org.freedesktop.Platform.ffmpeg-full
```
Проверка:
```bash
flatpak run org.freedesktop.Platform.ffmpeg-full ffmpeg -formats | grep pipewire
# -> D  pipewire
```
Запуск:
```bash
flatpak run org.freedesktop.Platform.ffmpeg-full ffmpeg \
  -f pipewire -i default out.mkv
```
---
2: OBS ffmpeg (если OBS стоит)
OBS уже тащит свой ffmpeg с pipewire
Путь обычно:
```bash
/usr/lib/obs-plugins/ffmpeg/ffmpeg
```
почекать:
```bash
/usr/lib/obs-plugins/ffmpeg/ffmpeg -formats | grep pipewire
```
